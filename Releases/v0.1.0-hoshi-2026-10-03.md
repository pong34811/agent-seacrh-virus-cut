### ค่าที่ใช้ใน pipeline

- **คะแนนหน้าต่าง** = 0.30 ความดังเฉลี่ย + 0.15 ค่ายอดสูงสุด + 0.30 การพุ่งหลังเงียบ + 0.25 สัดส่วนช่วงดังต่อเนื่อง (z-score ภายในวิดีโอ แล้ว min-max เป็น 0-1)
- **ลดคะแนนช่วงที่ไม่มีคนพูด:** ถ้าสัดส่วนเสียงพูดต่ำกว่า 0.2 คูณคะแนนด้วย 0.3 (เสียงพูด = ดังกว่า percentile ที่ 95 ลบ 30 dB)
- **จำนวนช่วงที่เลือก:** 20 ช่วงต่อชั่วโมงก่อนรวมช่วง
- **ถอดเสียง:** faster-whisper `large-v3`, float16, ภาษาไทย, โหมด batch (`batch_size=16`, `beam_size=1`) บน GPU
- **เพิ่มเสียงเฉพาะสำเนาที่ใช้ถอดเสียง:** `highpass=f=80,loudnorm=I=-16:TP=-1.5:LRA=11` ไม่ปรับ wav ที่ใช้คัดช่วง เพราะจะลบความต่างของความดังที่ใช้จับช่วงน่าสนใจ
- **Timeline:** `end_frame` แบบ exclusive, `record_frame` 0, fps ต้นฉบับเท่ากับ fps Timeline (60) จึงไม่เกิดปัญหาปัดเศษข้าม fps

## 9. วิธีรันงานถัดไป

2. สร้าง venv ใน `work/.venv` ติดตั้ง numpy, faster-whisper, pillow, pytest (GPU NVIDIA บน Windows เพิ่ม `nvidia-cublas-cu12`, `nvidia-cudnn-cu12`) แล้วทดสอบ GPU ด้วย `python tools/gpu_smoke.py`
3. จาก `work/`: `python pipeline.py inventory`, `features`, `shortlist`, `transcribe` (รันเบื้องหลัง), `sheets`, `packets`, `briefs`
4. ส่งไฟล์ `review/<id>.brief.md` ให้ subagent หนึ่งตัวต่อวิดีโอ แล้วรัน `python -m pytest tests` เป็นด่านตรวจ
5. บันทึกผล `probe_media_pool` ลงไฟล์ รัน `python resolve_clips.py <ไฟล์>` แล้ว `python build_timelines.py` และใช้ `python build_timelines.py calls <เริ่ม> <จบ>` สร้าง payload ให้ Resolve MCP
6. ให้ผู้ใช้ยืนยัน Playback frame rate เอง และแจ้งรายการคลิปที่ผู้รีวิวไม่มั่นใจ
